# Tend roadmap

## Phase 1 — core MVP

- [x] Authentication, migrations, categories, brain dump, goals, tasks, flexible habits
- [x] Mood/energy check-ins, weekly planner, dashboard, basic descriptive insights
- [x] Responsive API integration, Docker, CI, Swagger, architecture/schema docs
- [ ] Habit completion state endpoint and monthly calendar
- [ ] Goal progress history and task postponement-barrier prompts
- [ ] Refresh tokens, durable auth rate limiting, account export/deletion

## Phase 2 — personal wellbeing

- [ ] Personal experiments and timelines
- [ ] Optional mental-health journal and physical-health metrics
- [ ] Medical appointments, encrypted/private attachments, reminders
- [ ] Advanced recurrence, time-zone edge cases, richer analytics

## Phase 3 — optional intelligence

- [ ] Consent-driven task decomposition and brain-dump structuring
- [ ] Weekly summaries and pattern retrieval with provenance
- [ ] No sensitive external AI transfer without explicit, granular consent
